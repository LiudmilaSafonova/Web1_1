# WindyMeow

Интернет-магазин товаров для кота на яхте. Проект выполнен на HTML, CSS и JavaScript без использования фреймворков.

В магазине есть каталог товаров, корзина с изменением количества и подсчётом суммы, сохранение данных в `localStorage` и форма оформления заказа.
